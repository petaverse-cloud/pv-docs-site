# Haustierprofile erstellen
Das Erstellen eines Haustierprofils in der WAGGURACY App ist ein wichtiger Schritt, um die Informationen zu Ihrem Haustier korrekt und aktuell zu halten.

Befolgen Sie die folgenden einfachen Schritte, um ein Haustierprofil in der WAGGURACY App zu erstellen:


1. App öffnen:

    Öffnen Sie die WAGGURACY App auf Ihrem Android- oder iOS-Gerät.
2. Anmelden:

    Melden Sie sich bei Ihrem WAGGURACY Konto an, falls Sie dies noch nicht getan haben.
3. Haustierprofil aufrufen:
  
    Tippen Sie auf **User** > **Pet info**
4. Neues Haustier hinzufügen:
 
    Tippen Sie im Bereich für Haustierprofile auf **+**. Dadurch wird der Vorgang zum Hinzufügen eines neuen Haustiers zu Ihrem Konto gestartet.
5. Haustierdaten eingeben:
  
    Geben Sie wichtige Informationen zu Ihrem Haustier ein, z. B. **Name**, **Rasse**, **Tierart**, **Geburtsdatum** und **Geschlecht**. Sie können außerdem ein Foto Ihres Haustiers hochladen.
6. Änderungen speichern:

    Nachdem Sie die erforderlichen Informationen eingegeben haben, speichern Sie die Änderungen, um das neue Haustierprofil zu erstellen.

Durch das Erstellen von Haustierprofilen in der WAGGURACY App haben Sie genaue Informationen jederzeit griffbereit und können Ihre Haustiere bestmöglich betreuen und ihre Aktivitäten verfolgen. Wenn Sie mehrere Haustiere haben, wiederholen Sie diese Schritte, um für jedes Haustier ein Profil zu erstellen und die jeweiligen Informationen aktuell zu halten.
