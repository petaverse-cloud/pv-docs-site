# Haustierprofile löschen
In der WAGGURACY App können Sie nicht mehr benötigte Haustierprofile löschen. Hier finden Sie die einfachen Schritte zum Löschen eines erstellten Haustierprofils in der WAGGURACY App:

![delete](/img/pet/Deleting.jpg)

1. App öffnen:

    Öffnen Sie die WAGGURACY App und melden Sie sich bei Ihrem Konto an.
2. Haustierprofil aufrufen:

   Tippen Sie auf **Benutzer** > **Haustierinformationen**.
3. Haustier auswählen:

     Tippen Sie auf das Haustierprofil, das Sie löschen möchten.
4. Haustier löschen:

    Tippen Sie auf **Löschen**, um den Löschvorgang zu starten.
5. Löschung bestätigen:

    Bestätigen Sie, dass Sie das Haustierprofil löschen möchten.
6. Abschluss:

    Nach der Bestätigung werden das Haustierprofil und die zugehörigen Daten dauerhaft aus Ihrem WAGGURACY-Konto gelöscht.

Das Löschen der Haustierinformationen kann nicht rückgängig gemacht werden und alle zugehörigen Daten werden entfernt. Überprüfen Sie Ihre Auswahl sorgfältig, bevor Sie mit dem Löschen fortfahren.
