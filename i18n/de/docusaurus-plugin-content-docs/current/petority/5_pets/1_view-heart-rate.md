# So zeigen Sie den Puls Ihres Haustiers in WAGGURACY an
Mit der Pulsaufzeichnung des PHAST 1 können Sie die Pulsdaten Ihres Haustiers im Blick behalten und wertvolle Einblicke in seine Gewohnheiten und sein Wohlbefinden erhalten.

Hier finden Sie eine kurze Anleitung, wie Sie die Pulsdaten Ihres Haustiers mit WAGGURACY anzeigen können:

1. Öffnen Sie die WAGGURACY App:

	Laden Sie zunächst die WAGGURACY App auf Ihr Smartphone herunter und installieren Sie sie. Melden Sie sich anschließend bei Ihrem Konto an.
2. Wählen Sie Ihr Haustier aus:

	Navigieren Sie in der App zu Ihrer Liste der registrierten Haustiere.
3. Rufen Sie die Gewohnheitsdaten Ihres Haustiers auf:

	Tippen Sie auf den Namen oder das Bild des Haustiers, dessen Profil Sie aufrufen möchten.

## Pulsdaten anzeigen:

Auf der Seite **Gewohnheiten** finden Sie Informationen zum [Pulsverlauf](/docs/petority/features/realtime-heartrate-monitoring), der normalerweise in Schlägen pro Minute (bpm) angezeigt wird. So können Sie jederzeit den aktuellen Puls Ihres Haustiers einsehen.

## Pulsbenachrichtigungen einrichten:
Sie können möglicherweise Pulsbenachrichtigungen konfigurieren. So [werden Sie benachrichtigt](/docs/petority/notification/type), wenn der Puls Ihres Haustiers als ungewöhnlich erkannt wird, und können entsprechend reagieren.
## Pulsverlauf:
Die App bietet in der Regel Einblicke in die Pulsentwicklung und [historische](/docs/petority/features/health-monitoring) Daten Ihres Haustiers, sodass Sie dessen Pulsmuster im Laufe der Zeit besser verstehen können.
