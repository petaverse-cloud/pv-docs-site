# So zeigen Sie die Aktivität Ihres Haustiers in WAGGURACY an
Um die Aktivität Ihres Haustiers in WAGGURACY anzuzeigen, folgen Sie diesen Schritten in der WAGGURACY App:

1. Öffnen Sie die WAGGURACY App:

	Laden Sie die WAGGURACY App herunter und installieren Sie sie. **Melden Sie sich** anschließend bei Ihrem Konto an.
2. Auf die Aktivität des Haustiers zugreifen:

	Tippen Sie auf **Gewohnheiten**.
3. Aktivität des Haustiers anzeigen:

	Auf der Seite **[Gewohnheiten](/docs/petority/features/health-monitoring)** können Sie verschiedene Aktivitätsinformationen zu Ihrem Haustier anzeigen, z. B. Schritte, Puls und weitere Aktivitätsdaten aus der Vergangenheit.

	![step](/img/health/Health.jpg)
    
+ Zeitraum auswählen:

	Sie können **verschiedene Zeiträume** auswählen, um den Aktivitätsverlauf Ihres Haustiers anzuzeigen. Mit WAGGURACY können Sie die Aktivität für den **Tag**, die **Woche** oder den **Monat** überprüfen.

	![Health](/img/health/time.jpg)

**Grafiken und Diagramme:**

Die App stellt die Aktivitätsmuster Ihres Haustiers in der Regel übersichtlich anhand von Grafiken und Diagrammen dar. Sie können Details wie Schrittzahl, aktive Zeit, Ruhezeit und mehr einsehen.

<!-- ![step](/img/get-to-know/Comprehensive-Health-Insights.gif) -->
![home-step](/img/get-to-know/Exercise-Monitoring-and-Real-time-Heart-Rate-Tracking.jpg)

**Benachrichtigungen:**

![alert](/img/pet/Notification.jpg)

Die App sendet außerdem Benachrichtigungen, damit Sie die Aktivität Ihres Haustiers im Blick behalten und sein Wohlbefinden unterstützen können.
