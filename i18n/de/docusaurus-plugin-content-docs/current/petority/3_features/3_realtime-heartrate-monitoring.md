# Pulsaufzeichnung mit sofortiger Synchronisierung

WAGGURACY verfügt über einen integrierten, hochempfindlichen Pulssensor, der **sofort synchronisierte Pulsdaten bereitstellt** und **Pulstrends fortlaufend aufzeichnet**. So behalten Sie das tägliche Wohlbefinden Ihres Haustiers auf einen Blick im Blick.

![Instant Sync Pulse](/img/heart/Heart-Rate1.jpg)

**Vorteile:**

+ **Sofortiger Pulswert:** Ein hochempfindlicher Pulssensor stellt nach einem Tippen in der App Pulsdaten auf Abruf bereit.
+ **Fortlaufende Trendaufzeichnung:** Zeichnet Pulstrends über einen längeren Zeitraum auf, sodass Sie tägliche, wöchentliche und längerfristige Muster einfach einsehen können.
+ **Visuelle Hinweise für verschiedene Bereiche:** Die App zeigt für unterschiedliche Pulsbereiche verschiedene Farben an, damit Sie den aktuellen Pulsbereich Ihres Haustiers schnell erfassen können.
+ **Kontext zu Aktivität und Ruhe:** Pulswerte werden zusammen mit Aktivitäts- und Ruhephasen (z. B. aktives Spielen, Schlafen) angezeigt, wodurch sich Trends im Alltag leichter einordnen lassen.
+ **Speziell für Haustiere entwickelt:** Der Pulssensor verwendet einen adaptiven Algorithmus, der speziell für Haustiere entwickelt wurde. **NICHT** bei Menschen oder nicht lebenden Oberflächen verwenden.

**Hinweise zum Puls:** Der Puls eines Haustiers kann abhängig von Faktoren wie Alter, Rasse, Aktivitätsniveau und emotionalem Zustand variieren. Während des Spielens oder bei körperlicher Aktivität kann der Puls steigen und während der Ruhe sinken. Die Farbanzeigen dienen ausschließlich als schnelle visuelle Orientierung und stellen keine diagnostischen Grenzwerte oder medizinischen Bewertungen dar.

**Wichtige Hinweise / Haftungsausschluss**

**KEIN MEDIZINPRODUKT.** Dieses Produkt ist ein Gerät für das allgemeine Wohlbefinden und nicht für medizinische Zwecke bestimmt. Alle Daten (einschließlich Pulsmessungen und Trends) dienen ausschließlich als **tägliche Orientierung**. Aufgrund von Synchronisierungsintervallen und Umgebungsfaktoren werden Daten möglicherweise nicht unmittelbar synchronisiert angezeigt. Dieses Gerät darf nicht zur medizinischen Diagnose oder als Ersatz für professionelle tierärztliche Beratung verwendet werden. Bei Bedenken hinsichtlich der Gesundheit Ihres Haustiers wenden Sie sich bitte an einen Tierarzt.

### Verwendung:

1. **Funktion aufrufen:** Öffnen Sie die **WAGGURACY App** auf Ihrem Android- oder iOS-Gerät und melden Sie sich an.
2. **Zu Puls wechseln:** Tippen Sie im App-Menü auf den Bereich **„Gewohnheiten"**.
3. **Haustier auswählen:** Wenn Sie mehrere Haustiere in der App registriert haben, wählen Sie das Haustier aus, dessen Puls Sie anzeigen möchten.
4. **Sofort synchronisierte Messung anzeigen:** Tippen Sie, um eine sofortige Pulsmessung mit Synchronisierung zu starten, oder sehen Sie sich historische Trends im Trenddiagramm an.

Für diese Funktion ist ein kompatibles **WAGGURACY-Gerät** mit Pulsaufzeichnung sowie eine stabile Verbindung zur App erforderlich. Die Pulsdaten dienen ausschließlich als allgemeine Orientierung. Wenden Sie sich an einen Tierarzt, wenn Sie professionelle Unterstützung bei der Einordnung der Pulsdaten Ihres Haustiers benötigen.
