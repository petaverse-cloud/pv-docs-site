# Geofences für die Sicherheit Ihres Haustiers
Mit der Geofence-Funktion von WAGGURACY können Sie virtuelle Grenzen für Ihr Haustier festlegen und so dazu beitragen, dass es sich beim Herumlaufen innerhalb sicherer Bereiche aufhält. Sie können damit den Aktivitätsbereich Ihres Haustiers verfolgen und erhalten intelligente Warnungen und Benachrichtigungen über dessen Standort und Bewegungen.

Für unterschiedliche Nutzungsszenarien bietet WAGGURACY zwei spezielle Geofence-Typen: Home Fence zur Definition Ihres häuslichen Umfelds und Custom Fence, mit dem Sie flexible Bereiche für bestimmte Anforderungen erstellen können.

![fence-map](/img/fence/Fence.jpg)

## Home Fence einrichten
Möchten Sie benachrichtigt werden, wenn Ihr Haustier Ihr Zuhause verlässt oder es betritt? Dann können Sie einen Geofence einrichten, der einen sicheren Aktivitätsbereich für Ihr Haustier definiert.

![fence edit](/img/fence/Fence4.jpg)

1. WAGGURACY App öffnen:

	Öffnen Sie die WAGGURACY App auf Ihrem Android- oder iOS-Gerät.
2. Bei Ihrem Konto anmelden:

	Melden Sie sich bei Ihrem WAGGURACY-Konto an.
3. Zum Geofence-Bereich wechseln:

	Tippen Sie auf **Benutzer** > **Gerätekachel**.
4. Ihren Geofence bearbeiten:

	Tippen Sie auf **Home Fence** > **Bearbeiten**.
5. Ihren Heimatstandort auswählen:

	Wählen Sie Ihren Heimatstandort aus, um den sicheren Bereich für Ihr Haustier einzurichten.
6. Geofence-Einstellungen bestätigen:

	Nachdem Sie Ihren Heimatstandort festgelegt haben, folgen Sie den Anweisungen in der App, um den Umgebungsscan abzuschließen und die Einrichtung des Home Fence zu beenden.

## Custom Fence einrichten
Möchten Sie benachrichtigt werden, wenn Ihr Haustier einen bestimmten Bereich verlässt oder betritt? Dann können Sie einen Geofence einrichten, der einen sicheren Aktivitätsbereich für Ihr Haustier definiert.

![fence edit](/img/fence/Fence5.jpg)

1. WAGGURACY App öffnen:

	Öffnen Sie die WAGGURACY App auf Ihrem Android- oder iOS-Gerät.
2. Bei Ihrem Konto anmelden:

	Melden Sie sich bei Ihrem WAGGURACY-Konto an.
3. Zum Geofence-Bereich wechseln:

	Tippen Sie auf **Benutzer** > **Gerätekachel**.
4. Ihren Geofence bearbeiten:

	Tippen Sie auf **Custom Fence** > **Bearbeiten**.
5. Form des Geofence anpassen:

	Sie können zwischen verschiedenen Geofence-Formen wählen, darunter **Kreis** und **Rechteck**, oder eine individuelle Form erstellen, die Ihren Anforderungen am besten entspricht.
6. Geofence-Einstellungen bestätigen:

	Nachdem Sie die Form und Grenzen des Geofence festgelegt haben, tippen Sie auf **OK**, um die Einstellungen zu bestätigen.

## Benachrichtigungen zu Geofence-Ereignissen:

![Steps](/img/get-to-know/Instant-Fence-Alerts.jpg)


Sie erhalten **[Benachrichtigungen zu Geofence-Ereignissen](/docs/petority/notification/fence-event)**, wenn Ihr Haustier den definierten Geofence-Bereich betritt oder verlässt.

Durch Tippen auf die **Warnbenachrichtigung** können Sie **detaillierte** Informationen zum Standort Ihres Haustiers anzeigen.

## Geofences bearbeiten und löschen:
Wenn Sie die Grenzen oder andere Parameter Ihres Geofence **ändern** möchten, gehen Sie einfach wie folgt vor:

![Editing and Deleting](/img/fence/Fence2.jpg)

1. Öffnen Sie die WAGGURACY App und **melden Sie sich** bei Ihrem Konto an.
2. Tippen Sie auf **Benutzer** > **Gerätekachel** > **Geofence**.
3. Tippen Sie auf **Bearbeiten**.
+ Zum Bearbeiten nehmen Sie die erforderlichen Änderungen an Form oder Grenzen des Geofence vor und speichern Sie anschließend die aktualisierten Einstellungen.
+ Zum Löschen können Sie den Geofence **entfernen**. Beachten Sie, dass beim Löschen eines Geofence auch alle damit verbundenen Daten gelöscht werden.

Wenn Sie einen bestimmten Geofence nicht mehr benötigen, können Sie ihn **deaktivieren**.

![switch](/img/fence/Fence3.jpg)

Die Geofence-Funktion von WAGGURACY schafft eine zusätzliche Sicherheitsebene, indem Sie bestimmte Bereiche für Ihr Haustier festlegen können. Sie erhalten Benachrichtigungen, wenn sich Ihr Haustier außerhalb dieser Bereiche bewegt, sodass Sie informiert bleiben und eine sicherere Erkundung im Alltag unterstützen können.
