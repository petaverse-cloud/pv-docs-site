title: "Passwort zurücksetzen"
---

Wenn Sie das Passwort Ihres WAGGURACY-Kontos vergessen haben, müssen Sie sich keine Sorgen machen. In dieser Anleitung werden die einfachen Schritte zum Zurücksetzen Ihres Passworts und zur Wiederherstellung des Zugriffs auf Ihr Konto beschrieben.
### Passwort über die Anmeldeseite zurücksetzen:

1. Anmeldeseite aufrufen:

    Wenn Sie Ihr Passwort vergessen haben, rufen Sie die WAGGURACY-Anmeldeseite auf.
2. Zurücksetzen des Passworts starten:

    Klicken Sie auf der Anmeldeseite auf **„Passwort vergessen"**.
3. Bestätigungs-E-Mail erhalten:

    Nach dem Klicken wird ein Bestätigungscode an die mit Ihrem Konto verknüpfte E-Mail-Adresse gesendet.
4. E-Mail-Verifizierung abschließen:

    Prüfen Sie Ihren Posteingang auf die Bestätigungs-E-Mail und befolgen Sie die darin enthaltenen Anweisungen, um die Kontoverifizierung abzuschließen und Ihre Identität zu bestätigen.
5. Neues Passwort festlegen:

    Nach erfolgreicher Verifizierung können Sie ein neues Passwort für Ihr Konto festlegen. Achten Sie darauf, ein sicheres Passwort zu verwenden, das die von WAGGURACY festgelegten Anforderungen erfüllt.

### Passwort in der App zurücksetzen:

1. Kontosicherheit aufrufen:

    Tippen Sie auf **Benutzer** > **Kontosicherheit**.
2. Zurücksetzen des Passworts starten:

    Suchen Sie nach **„Passwort ändern"** und klicken Sie darauf.
3. Bestätigungs-E-Mail erhalten:

    Klicken Sie auf die Schaltfläche **„Code anfordern"**. Ein Bestätigungscode wird an die mit Ihrem Konto verknüpfte E-Mail-Adresse gesendet.
    
4. E-Mail-Verifizierung abschließen:

    Prüfen Sie Ihren Posteingang auf die Bestätigungs-E-Mail und befolgen Sie die darin enthaltenen Anweisungen, um die Kontoverifizierung abzuschließen.
5. Neues Passwort festlegen:

    Nach erfolgreicher Verifizierung können Sie ein neues Passwort festlegen. Stellen Sie sicher, dass es die erforderlichen Sicherheitsanforderungen erfüllt.
