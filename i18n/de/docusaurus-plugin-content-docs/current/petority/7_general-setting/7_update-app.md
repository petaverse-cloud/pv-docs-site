title: "WAGGURACY App aktualisieren:"
--- 

Wenn Sie Ihre WAGGURACY-App auf dem **neuesten Stand** halten, haben Sie Zugriff auf die **neuesten** Funktionen und Verbesserungen.

So können Sie die WAGGURACY-App auf verschiedenen Geräten aktualisieren:

+ iOS (Apple):
	1. Öffnen Sie die *App Store*-App auf Ihrem iPhone.
	2. Wählen Sie im unteren Menü **„WAGGURACY“** am unteren Bildschirmrand aus.
	3. Tippen Sie oben rechts auf Ihr Profilsymbol.
	4. Scrollen Sie nach unten zum Bereich **„Verfügbare Updates“**.

	Wenn *WAGGURACY* aufgeführt ist, tippen Sie neben der App auf **„Aktualisieren“**. Alternativ können Sie auf **„Alle aktualisieren“** tippen, um alle Ihre Apps zu aktualisieren.

+ Android:
	1. Öffnen Sie die *Google Play Store*-App auf Ihrem Android-Gerät.
	2. Tippen Sie oben rechts auf Ihr Profilbild.
	3. Wählen Sie **„Apps und Gerät verwalten“**.
	4. Suchen Sie nach dem Bereich **„Updates verfügbar“**.

	Wenn *WAGGURACY* aufgeführt ist, tippen Sie darauf und anschließend auf **„Aktualisieren“**.

**Wichtige Hinweise:**

+ Aufgrund *unterschiedlicher* Android-Versionen oder *angepasster* Benutzeroberflächen können die Schritte auf einigen Geräten leicht abweichen.
+ Wenn WAGGURACY nicht unter den verfügbaren Updates angezeigt wird, verwenden Sie bereits die neueste Version.
