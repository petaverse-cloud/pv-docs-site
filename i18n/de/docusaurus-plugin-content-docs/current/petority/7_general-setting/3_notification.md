# Alarmeinstellungen
WAGGURACY bietet eine Reihe von Alarmen, mit denen Sie über den **Status Ihres Haustiers** und den **Zustand des Geräts** informiert bleiben können. Mit diesen anpassbaren Einstellungen können Sie die Alarme entsprechend dem Wohlbefinden Ihres Haustiers und Ihren persönlichen Präferenzen konfigurieren.
## Alarme konfigurieren
In den Alarmeinstellungen können Sie Ihre Alarme wie folgt anpassen:

![type](/img/setting/Notification-Settings.jpg)

+ Alarmtypen auswählen:

	Wählen Sie die Alarmtypen aus, die Sie erhalten möchten, z. B. **Batterie**, **Signal**, **Puls**, **Zaun** und weitere. Aktivieren oder deaktivieren Sie die einzelnen Alarmtypen nach Bedarf.

+ Alarmkanäle:

	Legen Sie fest, wie Sie Alarme erhalten möchten. Tippen Sie auf den entsprechenden Bereich, um verschiedene Optionen entsprechend den Bedürfnissen Ihres Haustiers zu konfigurieren.


Diese Alarme werden zur einfachen Verwaltung im [Alarmcenter](/docs/petority/notification/type) der App angezeigt.

**Einstellungen regelmäßig überprüfen:**

Es empfiehlt sich, Ihre Alarmeinstellungen regelmäßig zu überprüfen, um sicherzustellen, dass Sie weiterhin wichtige Informationen über Ihr Haustier erhalten. Durch die Anpassung der WAGGURACY Alarmeinstellungen können Sie Ihr Haustier schützen und gleichzeitig unnötige Ablenkungen vermeiden. Verwalten Sie Ihre Alarme entsprechend Ihren Bedürfnissen und Prioritäten.
