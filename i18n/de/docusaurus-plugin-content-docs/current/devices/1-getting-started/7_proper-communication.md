# Ordnungsgemäße Kommunikation mit Ihren WAGGURACY Geräten
 Die folgenden Schritte helfen dabei, eine ordnungsgemäße Kommunikation zwischen Ihren WAGGURACY Geräten sicherzustellen:

+ Netzwerkverbindung:

	 Stellen Sie sicher, dass sowohl Ihr **WAGGURACY PHAST 1** als auch Ihr **Smartphone** mit einem stabilen Internetnetzwerk **verbunden** sind.

+ App und Firmware aktualisieren:

	Stellen Sie sicher, dass Sie die **neueste Version** der WAGGURACY App verwenden. Prüfen Sie außerdem, ob für Ihren WAGGURACY PHAST 1 **Firmware-Updates verfügbar** sind. Die Aktualisierung von App und Firmware kann Kompatibilitätsprobleme beheben.
