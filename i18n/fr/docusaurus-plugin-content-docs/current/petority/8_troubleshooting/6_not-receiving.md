title: "Vous n’avez pas reçu le code ?"
---

Si vous n’avez pas reçu le code de vérification, essayez les solutions suivantes :
+ Vérifiez votre dossier de courriers indésirables/spams pour y rechercher l’e-mail de vérification.
+ Assurez-vous que **noreplay@wagguracy.cloud** est enregistré comme expéditeur autorisé dans les paramètres de votre messagerie. Si ce n’est pas le cas, ajoutez cette adresse à votre liste blanche.

**Contacter le support :**

Si vous avez essayé toutes les étapes indiquées et que le problème persiste, contactez le service client pour obtenir de l’aide afin d’identifier et de résoudre le problème. Contactez-nous à l’adresse support@wagguracy.com.
