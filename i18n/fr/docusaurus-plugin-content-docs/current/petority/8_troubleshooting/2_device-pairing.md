# L’appairage de l’appareil a échoué
Si vous rencontrez des difficultés pour appairer votre PHAST 1, essayez les solutions suivantes :

1. Vérifier la compatibilité de l’appareil :

	Assurez-vous que votre smartphone est compatible avec PHAST 1. Vérifiez les caractéristiques et les exigences afin de vous assurer qu’il répond aux normes de compatibilité de PHAST 1.

2. Vérifier la connexion Bluetooth :

	Vérifiez que la fonction **Bluetooth** de votre smartphone est **activée** et que l’appareil est **détectable**. Désactivez puis réactivez le Bluetooth, puis essayez à nouveau d’effectuer l’appairage.

3. Vérifier que PHAST 1 est en mode appairage :

	Suivez les instructions du manuel d’utilisation de PHAST 1 pour vous assurer que l’appareil est en mode **appairage**. En règle générale, les appareils doivent être en mode appairage pour pouvoir se connecter à d’autres appareils.

4. Redémarrer les appareils :

	Certains problèmes de connexion temporaires peuvent être résolus en redémarrant votre smartphone et votre PHAST 1.

5. Mettre à jour l’application WAGGURACY :

	Assurez-vous d’utiliser la **dernière** version de l’application WAGGURACY. Vérifiez les [mises à jour disponibles](/docs/petority/general-setting/update-app) dans l’App Store ou sur le site officiel.

6. [Vérifier le niveau de batterie :](/docs/devices/battery-charging/battery-checking)

	Assurez-vous que PHAST 1 est suffisamment [chargé](/docs/devices/battery-charging/battery-charging). Un niveau de batterie faible peut entraîner des problèmes de connexion.

Si l’appairage échoue :
 
+ Vérifiez que le **Bluetooth** de votre téléphone est activé et qu’une connexion Internet est active.
+ Assurez-vous que l’appareil est suffisamment chargé.
+ Si l’appareil s’éteint pendant l’appairage, [**rechargez-le**](/docs/devices/battery-charging/battery-charging) avant de poursuivre.
+ Gardez l’appareil **à proximité** de votre téléphone pendant l’appairage.

Si l’appareil ne peut pas être détecté :

+ Assurez-vous que l’appareil est dans un état permettant sa **détection** et qu’il dispose d’une batterie **suffisamment** chargée.
+ Vérifiez que les autorisations **Bluetooth** sont activées sur votre téléphone.

**Contacter le support :**

Si vous avez essayé toutes les étapes indiquées et que le problème persiste, contactez le service client pour obtenir de l’aide afin d’identifier et de résoudre le problème. Contactez-nous à l’adresse support@wagguracy.com.
