# Que faire si la suppression du compte échoue :
Si vous rencontrez des problèmes lors de la suppression de votre compte WAGGURACY, vous pouvez suivre les étapes suivantes pour résoudre le problème :

1. Vérifier la connexion réseau :

	Assurez-vous que votre appareil est connecté à Internet et dispose d’une connexion réseau stable. La suppression du compte peut nécessiter une communication avec les serveurs WAGGURACY.

2. Effacer le cache et les cookies :

	Effacez le cache et les cookies de votre application mobile afin de vous assurer que les informations et le statut les plus récents sont affichés.

3. Essayer un autre navigateur ou appareil :

	Certains appareils peuvent parfois présenter des problèmes de compatibilité. Essayez d’utiliser un autre navigateur ou un autre appareil pour effectuer la suppression du compte.

Lors de la désactivation de votre compte, une vérification de sécurité est requise. L’application enverra un code de vérification à l’adresse e-mail associée à votre compte afin de garantir la sécurité.

Une fois la demande de suppression du compte envoyée, le compte entre dans une période de vérification de **30 jours**. Pendant cette période, le compte ne peut pas être utilisé. En appuyant sur **Conserver le compte**, vous pouvez annuler le processus de désactivation.

**Récupération du compte après suppression :**

+ Une fois la suppression définitive du compte effectuée, le compte ne peut plus être récupéré.
+ Après l'envoi d'une demande de désactivation du compte, la procédure de vérification prend généralement **30** jours. Pendant cette période, vous pouvez restaurer le compte, ce qui annule la demande de désactivation et vous permet de retrouver l'accès. Vous pouvez également tenter de récupérer votre compte depuis la page de connexion.
+ Une fois la vérification terminée et approuvée, le compte sera désactivé avec succès et toutes les données seront définitivement supprimées, rendant toute récupération impossible.

**Contacter le support :**

Si vous avez essayé toutes les étapes indiquées et que le problème persiste, contactez le service client pour obtenir de l’aide afin d’identifier et de résoudre le problème. Contactez-nous à l’adresse support@wagguracy.com.
