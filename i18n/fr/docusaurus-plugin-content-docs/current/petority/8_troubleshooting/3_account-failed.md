# Échec de la création du compte
Si vous rencontrez des problèmes lors de la création d’un compte WAGGURACY, ce guide propose des solutions possibles pour vous aider à résoudre le problème et à créer votre compte avec succès.
+ Lorsque vous créez un compte avec une adresse e-mail, veuillez choisir une adresse e-mail qui n'a pas déjà été enregistrée sur l'application WAGGURACY.
+ Si vous constatez que l’adresse e-mail que vous souhaitez utiliser est déjà associée à un autre compte, essayez d’utiliser une autre adresse e-mail pour l’inscription ou suivez la procédure de réinitialisation du mot de passe si vous pensez déjà disposer d’un compte.
+ Assurez-vous que le nom d’utilisateur et le mot de passe que vous saisissez respectent les exigences, notamment en matière de longueur et de types de caractères. Vérifiez attentivement qu’il n’y a pas d’erreurs ou d’informations manquantes.
+ Lorsque vous utilisez la connexion via un compte tiers pour l’application WAGGURACY, vous devez autoriser le fournisseur tiers à accéder aux informations de votre compte.

**Contacter le support :**

Si vous avez essayé toutes les étapes indiquées et que le problème persiste, contactez le service client pour obtenir de l’aide afin d’identifier et de résoudre le problème. Contactez-nous à l’adresse support@wagguracy.com.
