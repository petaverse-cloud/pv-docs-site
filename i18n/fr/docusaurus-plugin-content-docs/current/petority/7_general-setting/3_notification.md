# Paramètres des alertes
WAGGURACY propose différents types d’alertes qui vous permettent de rester informé du **statut de votre animal** et de l’**état de votre appareil**. Ces paramètres personnalisables vous permettent d’adapter les alertes en fonction du bien-être de votre animal et de vos préférences.
## Configurer les alertes
Dans les paramètres des alertes, vous pouvez personnaliser vos alertes comme suit :

![type](/img/setting/Notification-Settings.jpg)

+ Choisir les types d’alertes :

	Sélectionnez les types d’alertes que vous souhaitez recevoir, tels que **Batterie**, **Signal**, **Pouls**, **Clôture**, etc. Activez ou désactivez chaque type d’alerte selon vos besoins.

+ Canaux d’alerte :

	Définissez la manière dont vous souhaitez recevoir les alertes. Appuyez sur cette section pour configurer différentes options en fonction des besoins de votre animal.


Ces alertes apparaîtront dans le [centre des alertes](/docs/petority/notification/type) de l’application pour vous permettre de les consulter facilement.

**Vérifier régulièrement vos paramètres :**

Il est recommandé de vérifier régulièrement vos paramètres d’alertes afin de vous assurer que vous recevez toujours les informations importantes concernant votre animal. En personnalisant les paramètres d’alertes de WAGGURACY, vous pouvez contribuer à la sécurité de votre animal tout en évitant les distractions inutiles. Gérez vos alertes en fonction de vos besoins et de vos priorités.
