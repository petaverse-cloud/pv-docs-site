# Préférences d’unités :
WAGGURACY permet aux utilisateurs de personnaliser les unités utilisées pour différentes mesures, afin que les informations affichées correspondent à leurs préférences et habitudes.

![units](/img/setting/Unit-Settings.jpg)

+ Unités de distance :

	Définissez votre unité préférée pour mesurer les distances, par exemple les kilomètres ou les miles.

+ Unités de poids :

	Choisissez votre unité préférée pour mesurer le poids, par exemple les kilogrammes ou les livres.
