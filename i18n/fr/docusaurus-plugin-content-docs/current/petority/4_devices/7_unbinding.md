# Dissocier un appareil dans WAGGURACY
La dissociation d’un appareil dans WAGGURACY est une procédure simple qui vous permet de dissocier un appareil de votre compte.

Voici un guide étape par étape pour dissocier un appareil :

![unbinding](/img/unbind/Unbind.jpg)

1. Ouvrir l’application WAGGURACY :

	Ouvrez l’application WAGGURACY sur votre smartphone.
2. Accéder aux paramètres de l’appareil :

	Appuyez sur **User** > **Device Card** > **Settings**
3. Commencer la dissociation :
    
    Recherchez l’option **Unpair**. Appuyez sur cette option.
4. Confirmer la dissociation :

	Le système vous demandera de confirmer que vous souhaitez dissocier l’appareil. Après confirmation, l’appareil sera dissocié de votre compte dans l’application WAGGURACY.

**Conseils importants :**
+ Une fois ces étapes terminées, l’appareil **ne sera plus** associé à votre compte.
