# Notifications WAGGURACY pour un suivi complet de votre animal
WAGGURACY utilise différentes méthodes de notification afin de vous transmettre rapidement les informations importantes concernant vos animaux. Ces stratégies de notification sont conçues pour améliorer l’expérience globale de suivi et de gestion de vos animaux.
+ Notifications dans l’application :

	Vous recevrez des notifications directement dans l’application WAGGURACY, ce qui vous permet de les consulter et de les gérer facilement depuis l’application.

+ Notifications push :

	Grâce au service de notifications push de votre appareil mobile, WAGGURACY vous envoie des alertes en temps réel, afin que vous receviez les informations importantes même lorsque vous n’utilisez pas activement l’application.

+ Notifications par e-mail :

	WAGGURACY vous permet également de recevoir des notifications par e-mail, afin de rester informé même lorsque vous n’utilisez pas activement l’application.

Grâce à ces différentes méthodes de notification, vous pouvez accéder à tout moment aux informations essentielles concernant votre animal et votre appareil, afin d’assurer le meilleur accompagnement et suivi possible de vos animaux.
