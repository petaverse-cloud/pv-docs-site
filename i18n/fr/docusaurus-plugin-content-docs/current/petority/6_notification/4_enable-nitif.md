# Activer les alertes par message dans WAGGURACY
WAGGURACY propose **[différents types d’alertes](/docs/petority/notification/type)** pour vous tenir informé du bien-être de votre animal et de l’état de votre appareil.

Pour vous assurer de recevoir ces alertes importantes, suivez les étapes ci-dessous pour [activer les alertes par message dans l’application WAGGURACY](/docs/petority/general-setting/notification).

**Étape 1 :** Ouvrir l’application WAGGURACY

Téléchargez et ouvrez l’application WAGGURACY sur votre appareil Android ou iOS.

**Étape 2 :** Se connecter à votre compte

**Étape 3 :** Accéder aux paramètres des alertes

Appuyez sur **User** > **Settings**.

**Étape 4 :** Activer les alertes par message

Vous pouvez activer ou désactiver différents types d’alertes, tels que la **batterie**, le **signal**, le **[géorepérage](/docs/petority/notification/fence-event)**, etc., selon vos préférences.

Personnalisez vos paramètres d’alertes selon vos besoins et vos préférences, et profitez d’une tranquillité d’esprit en restant toujours informé des événements importants.
