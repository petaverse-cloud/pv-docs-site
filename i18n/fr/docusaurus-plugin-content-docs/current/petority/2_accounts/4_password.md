title: "Réinitialiser le mot de passe"
---

Si vous avez oublié le mot de passe de votre compte WAGGURACY, pas d’inquiétude. Ce guide présente les étapes simples pour réinitialiser votre mot de passe et récupérer l’accès à votre compte.
### Réinitialiser votre mot de passe depuis la page de connexion :

1. Accéder à la page de connexion :

    Si vous avez oublié votre mot de passe, accédez à la page de connexion WAGGURACY.
2. Commencer la réinitialisation du mot de passe :

    Sur la page de connexion, cliquez sur le bouton **« Mot de passe oublié »**.
3. Recevoir un e-mail de vérification :

    Après avoir cliqué, un code de vérification sera envoyé à l’adresse e-mail associée à votre compte.
4. Effectuer la vérification de l’adresse e-mail :

    Consultez votre boîte de réception pour trouver l’e-mail de vérification. Suivez les instructions fournies afin de terminer la vérification du compte et de confirmer votre identité.
5. Définir un nouveau mot de passe :

    Une fois la vérification terminée, vous pouvez définir un nouveau mot de passe pour votre compte. Assurez-vous qu’il est sécurisé et qu’il respecte les exigences définies par WAGGURACY.

### Réinitialiser votre mot de passe dans l’application :

1. Accéder à la sécurité du compte :

    Appuyez sur **Utilisateur** > **Sécurité du compte**.
2. Commencer la réinitialisation du mot de passe :

    Recherchez et cliquez sur **« Modifier le mot de passe »**.
3. Recevoir un e-mail de vérification :

    Cliquez sur le bouton **« Obtenir le code »**. Un code de vérification sera envoyé à l’adresse e-mail associée à votre compte.
    
4. Effectuer la vérification de l’adresse e-mail :

    Consultez votre boîte de réception pour trouver l’e-mail de vérification et suivez les instructions fournies afin de terminer la vérification du compte.
5. Définir un nouveau mot de passe :

    Une fois la vérification terminée, vous pouvez définir un nouveau mot de passe pour votre compte, en vous assurant qu’il respecte les critères de sécurité requis.
