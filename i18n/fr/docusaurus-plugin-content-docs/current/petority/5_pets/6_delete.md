# Supprimer un profil d’animal
Dans l’application WAGGURACY, vous pouvez supprimer les profils d’animaux dont vous n’avez plus besoin. Voici les étapes simples à suivre pour supprimer un profil d’animal créé dans l’application WAGGURACY :

![delete](/img/pet/Deleting.jpg)

1. Ouvrir l’application :

    Ouvrez l’application WAGGURACY et connectez-vous à votre compte.
2. Accéder au profil de l’animal :

   Appuyez sur **User** > **Pet info**.
3. Sélectionner un animal :

     Appuyez sur le profil de l’animal que vous souhaitez supprimer.
4. Supprimer l’animal :

    Appuyez sur **delete** pour commencer le processus de suppression.
5. Confirmer la suppression :

    Confirmez votre décision de supprimer le profil de l’animal.
6. Finalisation :

    Une fois la suppression confirmée, le profil de l’animal et les données associées seront définitivement supprimés de votre compte Wagguracy.

La suppression des informations de l’animal est irréversible et toutes les données associées seront supprimées. Vérifiez attentivement votre sélection avant de procéder à la suppression.
