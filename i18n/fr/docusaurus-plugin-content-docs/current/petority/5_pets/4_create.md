# Créer un profil pour votre animal
La création d’un profil pour votre animal dans l’application WAGGURACY est une étape essentielle pour conserver des informations précises et à jour sur votre animal.

Voici les étapes simples à suivre pour créer un profil d’animal dans l’application WAGGURACY :


1. Ouvrir l’application :

    Ouvrez l’application WAGGURACY sur votre appareil Android ou iOS.
2. Se connecter :

    Connectez-vous à votre compte WAGGURACY si ce n’est pas déjà fait.
3. Accéder au profil de l’animal :
  
    Appuyez sur **User** > **Pet info**
4. Ajouter un nouvel animal :
 
    Dans la section du profil de l’animal, appuyez sur **+**. Cela lancera le processus d’ajout d’un nouvel animal à votre compte.
5. Saisir les informations de l’animal :
  
    Renseignez les informations essentielles concernant votre animal, telles que son **nom**, sa **race**, son **espèce**, sa **date de naissance** et son **sexe**. Vous pouvez également ajouter une photo de votre animal.
6. Enregistrer les modifications :

    Une fois les informations nécessaires renseignées, enregistrez les modifications pour créer le nouveau profil de l’animal.

En créant des profils pour vos animaux dans l’application WAGGURACY, vous pouvez disposer d’informations précises à portée de main afin de leur offrir le meilleur accompagnement et suivi possible. Si vous avez plusieurs animaux, répétez ces étapes pour créer un profil pour chacun d’eux et maintenir leurs informations à jour.
