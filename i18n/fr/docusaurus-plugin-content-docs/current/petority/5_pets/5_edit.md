# Modifier le profil de votre animal
Il est essentiel de maintenir les informations de votre animal à jour pour assurer une gestion efficace de votre animal à l’aide de l’application WAGGURACY.

Voici un guide pour modifier les informations du profil de votre animal :

1. Ouvrir l’application :

    Ouvrez l’application WAGGURACY et connectez-vous à votre compte.
2. Accéder au profil de l’animal :

   Appuyez sur **User** > **Pet info**.
3. Sélectionner un animal :

     Appuyez sur l’animal dont vous souhaitez modifier les informations. Vous accéderez ainsi à la page détaillée du profil de l’animal sélectionné.
4. Mode modification :

    Recherchez le bouton **Edit** sur la page du profil de l’animal. Appuyez dessus pour accéder au mode modification.
5. Modifier les informations :
 
    En mode modification, vous pouvez modifier différentes informations concernant votre animal, telles que son **nom**, sa **race**, sa **date de naissance**, etc.
6. Enregistrer les modifications :

    Après avoir effectué les modifications nécessaires, appuyez sur **Save** pour enregistrer les modifications apportées au profil de votre animal.

N’oubliez pas que des informations de profil précises et à jour vous permettent de disposer des informations les plus pertinentes à portée de main afin d’offrir à vos animaux le meilleur accompagnement et suivi possible.
