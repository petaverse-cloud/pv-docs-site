# Assurer une communication correcte avec vos appareils WAGGURACY
 Voici les principales étapes pour garantir une communication correcte avec vos appareils WAGGURACY :

+ Connexion réseau :

	 Assurez-vous que votre **WAGGURACY PHAST 1** et votre **smartphone** sont tous deux **connectés** à un réseau Internet stable.

+ Mettre à jour l’application et le firmware :

	Assurez-vous d’utiliser la **dernière version** de l’application WAGGURACY. Vérifiez également si des **mises à jour du firmware** sont disponibles pour votre WAGGURACY PHAST 1. La mise à jour de l’application et du firmware peut résoudre les problèmes de compatibilité.
